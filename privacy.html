JANDI Uploader Privacy Policy

Effective date: October 5, 2026

This Privacy Policy explains how JANDI Uploader handles information when used as a local desktop helper for social media publishing.

1. Local operation

JANDI Uploader is designed to run locally on the user's computer. It does not operate a separate public backend service for storing user account data.

2. Information processed

The tool may process video files, titles, descriptions, hashtags, platform authorization credentials, and upload results as needed to perform user-requested publishing actions.

3. Authentication tokens

For supported platforms, OAuth access and refresh tokens may be stored locally on the user's computer so the user does not need to sign in for every upload. These tokens are used only to access the platform account authorized by the user.

4. Passwords

JANDI Uploader does not ask users to store their TikTok or Google account passwords inside the application. Authentication is handled through the platform's official sign-in flow where available.

5. Data sharing

Data is sent to third-party platforms only when required to perform actions requested by the user, such as uploading a video. Those platforms process data under their own privacy policies.

6. Local files

The tool may create local working files, upload metadata, and token files on the user's computer. The user can remove these local files at any time.

7. Retention

JANDI Uploader itself does not maintain a separate cloud database. Local files remain on the user's computer until the user deletes them.

8. Security

Users should keep client secrets, access tokens, refresh tokens, and local configuration files private and should not publish or share them.

9. Changes

This Privacy Policy may be updated when the tool's features or connected platform requirements change.
